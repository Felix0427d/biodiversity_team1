# Biodiversity Monitoring Project

## Sources and References

The following resources were used as references to understand how WAV audio files work and to develop our audio processing code.

- **Mgeier – Python Audio: Audio files with wave**  
  https://nbviewer.org/github/mgeier/python-audio/blob/master/audio-files/audio-files-with-wave.ipynb  
  This resource helped us understand how to read and manipulate WAV files using Python's `wave` module.

- **Warren Weckesser – wavio**  
  https://github.com/WarrenWeckesser/wavio  
  This project served as a reference for handling audio data with NumPy, particularly for reading and writing WAV samples with different bit depths.

- **Official Python Documentation – wave**  
  https://docs.python.org/3/library/wave.html  
  This documentation helped us understand and use the functions for reading and writing WAV files, as well as retrieving their properties (sample rate, number of channels, number of frames and sample width).
